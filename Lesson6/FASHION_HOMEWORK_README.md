# Fashion-MNIST ev tapşırığı

`fashion_cnn.ipynb` notebook-unu Lesson6 içində Jupyter / VS Code ilə açın və **Run All** edin.

Lazım olan paketlər: `pip install torch torchvision matplotlib numpy notebook`

İlk dəfə Fashion-MNIST yüklənməsi üçün internet lazımdır. Təlim bitəndə `fashion_cnn.pt` avtomatik yaranır. Dataset burada endirilə bilmədiyi üçün notebook hələ icra edilməyib və model faylı yaradılmayıb. 90% hədəfi üçün nəticəyə baxın; lazım olsa bonus modelini sınaqdan keçirin.
